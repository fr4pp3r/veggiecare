Detected Video Devices

Tests each node for real frames.

A USB webcam is a V4L2 node (/dev/video0, /dev/video1…). It is never /dev/ttyUSB0 — that is the NPK sensor's RS485 serial adapter. A Pi with libcamera also exposes many metadata-only nodes that open successfully but never deliver frames — use Find my camera to identify the real one, then set camera.device_path in config/config.yaml.
